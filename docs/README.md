# ClinicaSaaS — Documentation Index

Engineering foundation for ClinicaSaaS: a multitenant FHIR R4 SaaS platform
for small clinics in Argentina, built on Java 21 + Spring Boot 3 + Angular 18.

## Folder Structure

| Folder | Purpose |
|---|---|
| `architecture/` | High-level system design, component diagrams, data flow, integration maps |
| `standards/` | Coding conventions: backend (Java), frontend (Angular), database, Redis, security, API, Git |
| `testing/` | Testing strategy: unit, integration, frontend, coverage thresholds, tooling |
| `modules/` | Per-feature technical specifications (auth, RBAC, FHIR, agenda, etc.) |
| `adr/` | Architecture Decision Records — permanent log of significant design choices |
