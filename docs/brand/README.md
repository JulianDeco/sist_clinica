# Kuris — Brand Assets

## Nombre

**Kuris** — raíz fonética de *curar*, con K tech.
Sin presencia registrada en software clínico. Funciona en español, inglés y portugués.
Dominios candidatos: `kuris.app` · `kuris.health` (libres de DNS al 2026-06-17).

## Archivos

| Archivo | Uso |
|---|---|
| `kuris-logo.svg` | Logo horizontal — fondo claro (uso principal) |
| `kuris-logo-dark.svg` | Logo horizontal — dark mode |
| `kuris-icon.svg` | Ícono solo — favicon, app icon, avatar |

## Paleta

| Token | Hex | Uso |
|---|---|---|
| `brand-blue` | `#1D7AFF` | Color primario — ícono, acentos |
| `brand-blue-light` | `#3B82F6` | Variante dark mode |
| `brand-text-dark` | `#0F172A` | Tipografía sobre fondo claro |
| `brand-text-light` | `#F8FAFC` | Tipografía sobre fondo oscuro |
| `brand-muted` | `#64748B` | Tagline, textos secundarios |

## Tipografía

**Inter 700** para el wordmark. Fallback: Helvetica Neue, Arial.
Tracking: `-1px` en el wordmark. `+2.4px` en la tagline en versalitas.

## Ícono

**K** en negativo blanco sobre cuadrado redondeado azul.
La K es la inicial del nombre y refiere visualmente a *conexión* (brazos que convergen).
