## Descripción

Crear el proyecto Maven con estructura Clean Architecture para el backend
Java/Spring Boot. Incluye: pom.xml con dependencias core, application.yml
por perfil (dev/prod), migraciones Flyway V001..V008, Docker Compose
actualizado, y verificación de `/actuator/health`.

y debe estar en APPROVED antes de escribir las migraciones SQL.
