## Descripción
Implementar el recurso FHIR `ChargeItem` que registra el cargo económico de cada consulta. Sin este recurso, el módulo obra social no tiene datos históricos para calcular el porcentaje semanal de facturación.

## Campos mínimos del ChargeItem

```json
{
  "resourceType": "ChargeItem",
  "status": "billed",
  "subject": {"reference": "Patient/uuid"},
  "performer": [{"actor": {"reference": "Practitioner/uuid"}}],
  "occurrenceDateTime": "2024-03-15T10:00:00Z",
  "quantity": {"value": 5000.00},
  "service": [
    {
      "concept": {
        "coding": [{"system": "obra-social", "code": "iapos", "display": "IAPOS"}]
      }
    }
  ]
}
```

## Background task al fulfillir un Appointment

```python
# appointment.py — al PUT status=fulfilled
async def on_appointment_fulfilled(appointment_id: str, db, redis):
    # obtener datos del appointment
    appointment = await get_appointment(appointment_id, db)
    charge_item = build_charge_item(
        patient_ref=appointment["participant"][0]["actor"]["reference"],
        practitioner_ref=appointment["participant"][1]["actor"]["reference"],
        occurrence=appointment["end"],
        obra_social_code=await get_patient_obra_social(appointment, db),
    )
    await create_fhir_resource("ChargeItem", charge_item, db)
    await invalidate_obra_social_cache(practitioner_id, obra_social_code, redis)
```
