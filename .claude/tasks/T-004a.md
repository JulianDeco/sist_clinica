## Descripción
Reemplazar `Base.metadata.create_all` por Alembic como único mecanismo de migraciones. Sin esto, T-004 no puede generar migraciones correctamente.

## Archivos a crear/modificar

| Archivo | Rol |
|---|---|
| `backend/alembic.ini` | Config de Alembic (generado con `alembic init`) |
| `backend/alembic/env.py` | Conectar Alembic a `AsyncEngine` via `run_sync` + importar todos los modelos |
| `backend/alembic/versions/001_auth_initial.py` | Primera migración: tablas `users`, `refresh_tokens`, `authorization_codes` |
| `backend/app/main.py` | Eliminar `Base.metadata.create_all` del lifespan |

## Criterio de aceptación

- [ ] `alembic upgrade head` crea las tres tablas sin errores desde cero
- [ ] `alembic downgrade -1` + `upgrade head` sin errores
- [ ] `main.py` lifespan no contiene `create_all` ni `drop_all`
- [ ] `alembic current` muestra la revisión correcta
- [ ] La app levanta en Docker sin crear tablas automáticamente

## Configuración de env.py (patrón async)

```python
# alembic/env.py — fragmento clave
from sqlalchemy.ext.asyncio import create_async_engine
from app.core.config import settings
from app.core.database import Base
# importar todos los modelos para que Alembic los detecte:
from app.modules.auth.models import User, RefreshToken, AuthorizationCode  # noqa

def run_migrations_online():
    connectable = create_async_engine(settings.DATABASE_URL)
    async def run_async_migrations():
        async with connectable.connect() as connection:
            await connection.run_sync(do_run_migrations)
    asyncio.run(run_async_migrations())
```
