```sql

users(id UUID PK, email UNIQUE, hashed_password, is_active BOOL, created_at)

-- RBAC
roles(id UUID PK, name UNIQUE, description)
permissions(id UUID PK, resource VARCHAR, action VARCHAR, UNIQUE(resource, action))

```

## Migración de User.role_name

El modelo `User` actual tiene `role_name: String(50)` como columna inline. Esta migración debe:
1. Crear tablas `roles`, `permissions`, `role_permissions`, `user_roles`
2. Poblar `roles` con los tres roles base
3. Insertar en `user_roles` los registros existentes (leer `role_name` de cada `User`, buscar el `Role` correspondiente)
4. Eliminar la columna `role_name` de la tabla `users`
5. Actualizar `auth/service.py` para obtener `role_name` via `SELECT roles.name FROM user_roles JOIN roles WHERE user_id = ?`
